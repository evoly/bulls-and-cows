# Bulls and Cows 🐂🐄

A small educational project based on the classic **Bulls and Cows** logic game.

Built as part of my learning journey to practice **TypeScript**, DOM manipulation, modular code structure, and unit testing.

### 🎮 [Play the Game](https://evoly.github.io/bulls-and-cows/)

### Features

- Customizable code length (2–6 digits)
- Four numeral systems: binary, octal, decimal, and hexadecimal
- Game history and timer
- Local leaderboard using LocalStorage
- Unit tests with Vitest

### Tech Stack

TypeScript, HTML, CSS, Vite, Vitest.

### Inspiration

The design and gameplay were inspired by [Bulls and Cows Game](https://www.bullsandcowsgame.com/).

### Project

Created as part of the [RS School](https://rs.school/) learning program.
